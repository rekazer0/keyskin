# 搜狗 SSF 文件树：重复配置入口修复

调查日期：2026-10-18。以搜狗输入法 Android 20.17.0 的皮肤格式为对照。本文只记录格式关系与编辑器行为，不收录第三方应用代码。

## 配置与图片的关系

`phoneSkin.ini` 是当前外观的配置入口；`images_config.ini` 把资源名映射到图片，`image_list.ini` 让样式引用相应的资源名。不同外观可以有各自的配置。键设的分组只用于编辑器导航，不代表搜狗客户端也有同样的文件树。

## 编辑器修复

旧逻辑把「按键样式」和「图片资源」都指向 `phoneSkin.ini`，导致同一个配置出现两个入口。现在只有「按键样式」打开配置；图库有可用图片时，入口指向第一张可编辑图片并显示数量，没有图片时不生成图库入口。文件树、布局过滤和预览不改写皮肤原始文件。
