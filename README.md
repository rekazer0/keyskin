# 键设-bdiEditor

一个面向百度输入法 iOS `.bdi` / Android `.bds`、`.bda`，搜狗手机输入法 `.ssf` / `.mssf` 与手心输入法 `.sxi` 皮肤的可视化编辑器，支持 macOS、Windows 与 Android，并提供可在手机浏览器中使用的在线版本。它将皮肤文件、键盘布局、按键样式和图片资源集中到同一个实时预览工作流中，并提供新建、编辑、撤销/重做、保存、跨格式转换与分享能力。

桌面端采用文件导航、实时画布与属性检查器三栏布局；移动端改为可调节的上下分屏，方便在文件、画布和属性之间切换。界面支持浅色/深色模式、设备安全区与轻量毛玻璃效果，皮肤文件始终在本地处理。

## 支持的格式

| 格式 | 打开 / 保存 | 可导出为 |
| --- | --- | --- |
| `.bdi` / `.bds` | 百度输入法 iOS / Android 经典皮肤，原地编辑并写回 | `.bdi`、`.bds`、`.sxi`、`.ssf` |
| `.bda` | 百度输入法新版皮肤，按 `appearanceConfig` 识别 iOS / Android 家族 | `.bdi`、`.bds`、`.bda`（含 iOS / Android 两种）、`.sxi`、`.ssf` |
| `.ssf` / `.mssf` | 搜狗手机输入法皮肤，支持普通 ZIP 与加密容器，原地编辑并写回 | `.bdi`、`.bds`、`.bda`、`.ssf` |
| `.sxi` | 手心输入法皮肤，以 `skin.json` 为唯一数据源，原地编辑并写回 | `.bdi`、`.bds`、`.bda`、`.sxi` |

同一格式导出即另存；跨格式导出属于转换，搜狗、手心与百度皮肤之间的转换为实验性功能，导出前会列出可能降级的内容并等待确认。BDI/BDS 不直接导出 BDA；需要 BDA 时请从 BDA 皮肤或通过搜狗 / 手心转换路径导出。

## 快速上手

1. 点击左上角“打开”选择现有 `.bdi`、`.bds`、`.bda`、`.ssf` 或 `.sxi` 文件；也可点击“新建项目”，从百度官方模板或 5 套互联网整理 BDS 皮肤开始。
2. 在左侧“概览”中选择键盘布局、候选栏、工具栏或其他组件；切到“源文件”可像 Finder 一样浏览项目文件。
3. 使用画布上方控件切换设备、横竖屏、皮肤明暗和辅助线。选择手机时会按对应屏幕与安全区预览；触屏设备可用双指缩放和拖动平移画布。
4. 切换到“编辑模式”后点击按键，在右侧检查器修改对应属性。BDI/BDS 可编辑尺寸、位置、动作、颜色和图片；BDA 的几何与动作来自官方基础布局并只读，可编辑图片 ID、字体、字号和文字颜色；搜狗皮肤只修改视觉，按键排布由搜狗输入法决定；手心皮肤可在源码面板编辑 `skin.json` 片段，并调整按键前景样式与图片引用。点击图片缩略图可查看处理后的实际效果。
5. 多选时，macOS 使用 `Command + 单击`，Windows 使用 `Ctrl + 单击`；使用 `Shift + 单击`可连续选择两个按键之间的全部按键。
6. 百度皮肤中，右键选中的按键可复制或删除；右侧“源代码”会定位并整行高亮对应配置。
7. 完成后点击“保存”写回当前格式；也可通过左上角“导出”转换为其他格式。移动端和浏览器版可用“分享皮肤”交给系统分享（iOS 浏览器仅支持 BDI 或 iOS 版 BDA）。转换若存在降级内容，编辑器会先列出并等待确认。

在右上角“更多 → 设置”中按“外观 / 预览与画布 / 源代码 / AI 模型 / 关于”五类调整软件外观、默认预览设备、画布背景、安全区与辅助线、源码编辑与存储、模型服务和更新检查等选项。

## AI 设计

桌面应用可在“设置 → AI 模型”中配置模型服务（支持添加多个服务商和模型），再从右侧“AI 设计”描述希望的风格或改动，并在输入框下方选择设计力度（精修 / 均衡 / 大胆 / 3 个方向）和思考强度；顶部标签可在“当前面板”和“整个皮肤”之间切换修改范围。AI 代理由 pi 驱动，支持当前打开的 BDI/BDS/BDA/SSF/SXI 项目，并会按格式注入对应的皮肤结构知识。

AI 只能调用编辑器提供的项目检查、配置读取、INI / JSON 精确编辑、图片查看 / 改色 / 生成等接口；它没有 Shell、通用文件系统、文件创建 / 删除或新建二进制资源的权限。需要重绘或生成新图片时，需在“设置 → AI 模型 → 生图模型”中单独配置图片生成服务；简单的本地改色无需配置。对搜狗与手心皮肤，AI 同样只调整视觉和配置，不能增删按键或改变布局。

模型产生的内容先保存在内存草稿中。编辑器会在提交前再次检查文件版本和格式，BDA 配置还会经过 protobuf 写回验证；整轮修改只生成一个历史记录，可用一次“撤销”完整恢复。取消、模型报错或任一文件校验失败时不会应用草稿。

内置皮肤为互联网下载整理，如有侵权请联系作者下架。

## 主要特性

### 通用

- 打开、编辑并保存 `.bdi`、`.bds`、`.bda`、`.ssf` / `.mssf`、`.sxi`，也可从内置百度模板新建皮肤；保存时尽量保留未修改的文件、未知字段、ZIP 条目顺序、权限、时间扩展字段和原始压缩数据；
- 按当前格式自动显示可用的导出项；百度、搜狗与手心皮肤支持常用方向的转换导出（搜狗与手心之间不直接互转），并提供转换降级警告；
- 最近打开、可从源码目录重新打开皮肤、启动页模板与 `.bdi/.bds/.bda/.sxi` 文件关联（Finder / 资源管理器双击打开）；
- 百度官方 Android BDA 默认皮肤、官方 BDS 旧版皮肤、5 套互联网整理 BDS 皮肤、新建皮肤，以及撤销/重做和未保存保护；
- 新建、打开、保存、另存为和图片替换具有统一的进行中/成功/取消/失败反馈；文件错误会显示原生错误对话框；
- 可选择玻璃、马赛克、浅色、灰色或深色画布背景，并通过设置调整界面主题、密度、强调色和窗口材质。

### 百度皮肤（BDI / BDS / BDA）

- 按百度官方 protobuf 描述符解析 BDA 样式、面板、按键引用和资源 ID；结合安装包内的 1080 横竖屏基础几何显示各类布局，可编辑并保存按键图片 ID、字体、字号、文字颜色及包内 PNG，写回时保留未知 protobuf 字段；
- BDA 会按 `appearanceConfig`、面板集合和声音字段识别 iOS/Android 家族，可在 iOS 与 Android 两种 BDA 之间转换导出，而非仅修改 `SupportPlatform`；
- 自动识别九键、魔改九键和 26 键布局；
- 浅色/深色、竖屏/横屏实时预览；内置 iPhone 17 Pro、iPhone 17 Pro Max、Xiaomi 17、Pixel 10 Pro 与 Galaxy S25 Ultra 的厂商公布分辨率模板；
- 普通、按下/高亮、滑动方向和长按事件预览；交互预览中的字面按键可进入模拟输入区，可视化切换符号、数字、ABC 与 `Z+页面`，其他 `Fxx/Sxx` 只记录事件；
- 拖动、等宽、等高、对齐、分布和精确间距；
- 编辑显示文字、点击输入、上下左右滑和长按动作；编辑整体键盘高度、背景图片、背景透明色，以及按键背景/前景样式、字体、字号和正常/按下颜色；
- 多选按键后批量修改正常与按下图片；
- 动效可视化编辑：BDA 的 `animationConfig` 可按目标绑定与效果类型（透明度、缩放、位移、旋转、组合、帧、图片序列、粒子、Lottie、视频）修改并定点写回，保留未识别的 protobuf 字段；旧版 BDI/BDS 的 `anim.ini` 有独立动画检查器（概览、时间轴、基础/组合/帧/粒子参数、内联预览）。BDA 导出为旧版皮肤时会把动效转换成 `anim.ini` 并写回样式引用，无法表达的效果会在导出前提示；
- 解析和编辑皮肤名称、描述、作者、版本、平台与深色模式信息；
- 提供面板复制、替换键盘样式和 iOS 26 透明背景适配工具；
- 保留注释、空行、字段顺序、未知字段和未修改资源。

### 搜狗皮肤（SSF / MSSF）

- 打开普通 ZIP 或以 `Skin` 加密容器（版本 3）封装的搜狗手机皮肤，自动识别分辨率目录、白天/夜间外观与可用键盘；电脑版搜狗候选窗皮肤会被明确拒绝；
- 按搜狗官方键盘结构预览拼音九键、拼音全键、14 键、双拼、五笔、笔画、粤语、英文等布局，并支持横竖屏与明暗外观；
- 在检查器中按搜狗语义编辑键盘背景、候选栏、输入码、符号列、按键背景/前景、文字颜色、按键动画配置与音效；共享默认样式可一键复制为单个按键独立样式；动画配置可编辑，但画布不播放按键动画；
- 支持从皮肤内置图片和音频资源中选择、试听，图片换图时保留九宫格拉伸参数，并在多选按键时批量修改共同属性；
- 搜狗皮肤不含按键位置，因此不能增删按键或修改几何，只改视觉；可转换为 BDI/BDS/BDA（实验性），按键动画、动态背景等无对应内容时会在导出前提示降级；
- 面板复制可把整套分辨率目录复制为新的屏宽（如 `1080/` → `720/`），图片、拉伸参数与像素值按屏宽缩放，并登记到 `time.ini` 与 `phoneTheme.ini`；替换键盘样式写入键盘背景、候选栏或按键（每个分辨率目录各一份）；iOS 26 透明背景适配全部外观与分辨率的 `RootView` 和候选栏；
- 加密容器打开后会按普通 ZIP 编辑与保存，不再恢复加密；保存时只重写改动过的条目。

### 手心皮肤（SXI）

- 打开 `.sxi` 皮肤，兼容 Palm 原生的 `light/skin` 嵌套结构与编辑器导出的扁平结构，从 `skin.json` 生成布局、样式和切图预览；
- 覆盖拼音、英文、数字、符号、手写、表情等 60+ 种 Palm 面板类型，支持明暗外观、横竖屏、候选栏、气泡与按键状态预览；
- 可在源码面板直接编辑 `skin.json` 或对应 JSON 片段，保存仍写回 `skin.json`（包内存在 `info.json` 时同步其信息）；
- 检查器中可修改按键前景样式编号、选择图片样式与切片，并可新增图片样式后追加到前景引用；也可用 AI 设计按 JSON 片段调整样式；
- 面板复制按 `skin.json` 结构复制布局、方向、样式表或整套主题（可缩放）；替换键盘样式把图片切片写入 `info` 与新样式；iOS 26 透明背景适配全部键盘与候选栏，三者都写回 `skin.json`，每次一步撤销；
- 布局与样式在检查器中是 `skin.json` 的只读视图，几何和按键结构请在源码面板编辑对应 JSON；可导出为 BDI/BDS/BDA（实验性）。

### 预览与源码编辑

- 实时画布与设备外框，支持设备、横竖屏、明暗、辅助线和安全区切换；桌面端滚轮缩放、拖动平移，移动端双指缩放与平移；
- 配置源码提供 INI 语法高亮、选中 section 整行高亮与自动定位，编辑结果与画布实时同步；BDA 与 SXI 的 JSON 源码使用 JSON 高亮，并可定位到当前按键或样式；
- 源码编辑器支持查找替换、分节定位滚动条、补全、值解析与当前行释义；
- 语义化导航并可视化预览皮肤信息、布局、候选栏、符号、工具栏、手写和资源；提供统一样式库、图片资源选择器和图片切片查看；
- 资源检查器可搜索、预览与替换图片，声音资源支持试听。

## 范围

编辑器只还原键盘外观和按键状态，不实现百度、搜狗或手心输入法的候选算法、功能码执行或真实输入引擎。候选内容、输入区与页面切换属于编辑器模拟；未明确支持的 `Fxx/Sxx` 只显示含义或事件。

搜狗皮肤不包含按键位置，编辑器只修改视觉样式；手心皮肤以 `skin.json` 为准，检查器中的布局与样式视图只读。跨格式导出是格式转换，不保证每个按键动画、平台特有面板和资源在目标平台真机上的效果与原皮肤完全一致。

## 开发与构建

需要 Node.js 22.19+、Rust stable，以及对应平台的 Tauri 2 系统依赖。

```bash
npm install
npm run typecheck
npm run build
npm run tauri dev
```

桌面开发启动会自动选择空闲的本地端口，并同步给 Tauri 窗口；已有预览服务占用 1420 端口时无需关闭它。退出桌面开发命令时，其前端服务也会关闭。

构建 macOS `.app`：

```bash
CI=true npm run tauri build -- --bundles app
```

构建结果位于 `src-tauri/target/release/bundle/macos/`。

在 Windows 上构建 NSIS `.exe`：

```powershell
npm run tauri build -- --bundles nsis
```

构建结果位于 `src-tauri/target/release/bundle/nsis/`。推送 `v*` 标签会由 GitHub Actions 同时构建并上传 macOS `.dmg` 与 Windows `.exe` 到 GitHub Release。

## 兼容性

当前保证兼容项目测试样本所属的百度 iOS/Android 皮肤格式家族，并已用真实搜狗皮肤及手心皮肤样本覆盖打开、编辑、转换和往返流程。同格式编辑时，未知文件和字段会被保留；跨格式转换以已建模字段为准。其他历史格式仍需真实样本验证。搜狗、手心与百度之间的转换已完成预览和像素验证，但尚未在所有输入法真机上安装验证；复杂动画与平台特有资源可能降级，导出前会提示。详情见皮肤格式规范。

界面支持跟随系统、浅色和深色模式，并使用轻量毛玻璃；Windows 使用系统 Mica 窗口材质。macOS 发布包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证；首次打开若被 Gatekeeper 拦截，请在 Finder 中右键应用并选择“打开”。Windows 版本依赖系统 WebView2 Runtime。

## 隐私

除 AI 设计外，编辑器在本地处理皮肤文件，不上传皮肤、配置或图片。使用 AI 设计时，模型读取的已授权配置文本、当前画布预览图，以及用户附加的图片或文本会发送到用户在设置中配置的模型服务；使用生图模型时，画面描述会发送到对应的生图服务（部分服务商会同时收到参考图）。图片改色在本地完成。API 密钥以权限受限的 JSON 文件保存在本机应用配置目录中，请只使用可信的模型服务与 API 地址。
